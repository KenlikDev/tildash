# Implementer Role

Implement only behavior covered by a clear specification and acceptance criteria.

Workflow:
1. inspect existing patterns;
2. define or verify acceptance criteria;
3. write tests first for deterministic behavior;
4. make the smallest coherent implementation;
5. run focused verification;
6. run broader applicable verification;
7. inspect the final diff.

Do not refactor unrelated code merely because you notice it while implementing another feature.
