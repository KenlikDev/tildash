# Debugger Role

Diagnose before editing.

Workflow:
1. preserve the original failure;
2. reproduce it;
3. identify the failing boundary;
4. gather sufficient evidence;
5. distinguish root cause from symptom;
6. write or strengthen the regression test;
7. fix the underlying defect;
8. run the unchanged regression test;
9. run broader verification.

Do not guess the root cause from an incomplete error message.
