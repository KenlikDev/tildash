# Tildash Local Demo Content Terms v1

These terms apply only to the sample lesson records generated by scripts/run-local-learning-demo.ps1 for local acceptance testing.

The Russian explanations, prompts, example-dialogue composition, and exercise structure are authored for the Tildash local demo. They are intended to let the project owner evaluate the authoring, publication, download, and learner flow on a local development machine. They are not a reviewed production curriculum and must not be presented as fully verified instructional content.

The Crimean Tatar phrases were selected with reference to the official Ukrainian Ministry of Education model curriculum and the language-etiquette reference recorded in the demo script. This attribution does not assert that either referenced publication is public domain or grant rights to redistribute either source. The demo does not reproduce substantial prose from those publications.

The project may use these generated sample records to run and evaluate Tildash locally. The sample course must not be redistributed externally or published as a production learning resource. Before a production course is published, the content owner must review linguistic accuracy, provenance, and applicable licensing and replace this local-only terms identifier with the approved content license.

The terms identifier stored in sample provenance is Tildash Local Demo Content Terms v1.
